- **日期**: 2026-06-15
- **状态**: 已确认,待实施

## 1. 定位与目标

**一句话**:一个单用户、收盘级(EOD)、人在环中的 A 股板块轮动决策仪表盘。它不预测、不自动交易,只回答四件事:

1. **钱往哪走** —— 资金正从哪个板块流出、流入哪个板块。
2. **龙头是否真带动** —— 龙头涨了,板块/中军是否跟,还是单票脉冲。
3. **现在是哪个阶段** —— 冷启动 / 主升扩散 / 高位加速 / 龙头孤立 / 分歧退潮 / 低位修复。
4. **这一笔会不会动到我的担保比** —— 任何加仓决策先过风控关。

### 1.1 核心约束(决定了整个架构)

本系统服务一个**融资融券杠杆、高集中度、"不能亏"**的个人账户:

- 约 1800w 融资负债 + 利息,担保比约 169%,单一持仓集中度接近 100%。
- 杠杆 + 集中 ⇒ 一次 20% 回撤不仅亏 20%,还会把担保比推向强平线,可能在最低点被动强平。

**结论**:风控层(担保比 / 强平线 / 仓位)不是附加功能,而是**系统脊柱**。进攻(轮动 + 联动)永远建立在这层之上。

### 1.2 明确不做的(YAGNI / 非目标)

- ❌ 自动交易 / 下单 / 连券商账户(MVP 阶段)
- ❌ 盘中 tick / 秒级扫描(掘金、QMT 留到 Phase 3 验证有效后)
- ❌ 黑箱 AI 信号(杠杆账户上跑黑箱信号太危险)
- ❌ 全市场 5000+ 股扫描的复杂选股(聚焦人工股票池)

## 2. 系统架构(三层)

| 层 | 职责 | 技术 |
|---|---|---|
| **数据层 Data** | 拉取行情 / 资金流 / 板块成分,本地缓存,读股票池 | AKShare(免费,主力)+ Tushare Pro(token)+ Excel 股票池;缓存 parquet |
| **计算层 Compute** | 6 个核心指标、阶段状态机、历史联动统计、**风控引擎** | 纯 Python(无 IO),可单测 |
| **展示层 Display** | 5 个页面 | Streamlit + Plotly |

- **更新节奏**:每日收盘后全量更新;盘中可手动刷新 AKShare 快照。
- **数据流**:`数据层(拉取+缓存)` → `计算层(指标+状态+风控)` → `展示层(Streamlit 读计算结果渲染)`。展示层不直接调外部 API,只读缓存与计算输出,保证页面快、可离线复盘。

## 3. 数据层设计

### 3.1 数据源分工

| 用途 | 来源 | 备注 |
|---|---|---|
| 板块/个股日线行情 | AKShare `stock_zh_a_hist`;Tushare `daily` | Tushare 做干净历史回看 |
| 个股/板块资金流(主力净流入) | AKShare `stock_individual_fund_flow`、`stock_sector_fund_flow_rank` | 东财口径 |
| 估值(市盈率/换手) | Tushare `daily_basic` | |
| 板块成分 / 行业归属 | 股票池 Excel + 中证一级行业映射 | 见 3.3 |

> 所有外部拉取**必须**先写入 `data/cache/`(parquet),计算层与展示层只读缓存。带 `force_refresh` 参数手动绕过缓存。

### 3.2 缓存策略

- 行情/资金流按 `(symbol, date)` 增量缓存为 parquet。
- 缓存键含数据源与口径,避免 AKShare/Tushare 混淆。
- 提供 `refresh_eod()`(收盘后全量)与 `refresh_snapshot()`(盘中快照)两个入口。

### 3.3 股票池(双龙头模型)

种子文件:`data/universe/sector_leaders_seed.xlsx`(中证11一级行业 × 市值 Top10 = 110 只,数据日 2026-05-29,来源 AKShare 国证A指 399317)。

**关键设计 —— 每个板块要区分两类龙头**:

- **市值龙头(锚 / 中军)**:Excel 已按市值给出(如 证券板块的中信、华泰)。稳、跟涨。
- **人气龙头(领涨那个)**:带价格启动的题材龙头(如证券板块的东方财富、信息技术的拓维信息)。**市值未必大,需人工 input**,系统用"放量突破次数 / 领先板块天数"辅助识别。

股票池 = Excel 种子 + 人工加入的人气龙头,带 `leader_type ∈ {market_cap, momentum}` 标签。股票池是**动态观察网络**,不是静态名单。

## 4. 计算层 —— 指标体系

第一版只做 6 个核心指标(全部基于 EOD 数据,定义可实现):

| # | 指标 | 可实现定义 |
|---|---|---|
| 1 | **板块强度 Score** | 五项各算 z-score 后加权:① 相对收益(板块超额 vs 大盘) ② 成交额放大(今日/20日均) ③ 主力资金净流入 ④ 上涨家数扩散 ⑤ 龙头贡献。权重可配,默认等权。 |
| 2 | **扩散率** | 板块内上涨家数 ÷ 板块总家数。高 ⇒ 非单票支撑。 |
| 3 | **龙头贡献度** | Top3 龙头成交额 ÷ 板块总成交额。过高=独苗,过低=无主心骨。 |
| 4 | **龙头带动系数** | 龙头放量大涨后,板块 T+1/3/5 平均**超额**收益(历史回看统计)。判断"带头作用"的核心。 |
| 5 | **内部联动强度** | 板块核心股两两收益相关性均值 + 同涨概率。金融通常高,题材易分化。 |
| 6 | **阶段标签** | 状态机输出(见 §5)。 |

---

## 5. 阶段状态机

每日给每个板块打一个标签。规则示意(阈值集中在 config,可调):

| 状态 | 触发条件(示意) |
|---|---|
| **冷启动** | 20日趋势平 + 今日强度突升 + 资金转流入 |
| **主升扩散** | 强度高 + 扩散率 > 60% + 资金持续流入 |
| **高位加速** | 强度极高 + 成交额 > 20日均2倍 + 已连涨多日 |
| **龙头孤立** | 龙头大涨但扩散率 < 40% |
| **分歧退潮** | 强度回落 + 资金转流出 + 上涨家数收缩 |
| **低位修复** | 长期下跌后 + 资金小幅回流 + 扩散率回升 |

> 输出是**状态识别**,不是买卖信号。决策由人做。

## 6. 风控引擎(系统脊柱)

输入:账户参数(`data/account/account.json`,本地不进 git):总资产、融资负债、利息、现金、持仓(代码/股数/成本)。两条线可配:**警戒线默认 150%、平仓线默认 130%**(用户在账户配置里填涨乐财富通的真实值)。

计算输出:

1. **当前担保比** = 总资产 ÷ 融资负债;距警戒线 / 平仓线的余量。
2. **强平价模拟** —— 用当前持仓反推:主力持仓股跌到多少,担保比触平仓线。
   - 示例(用现有数推算):负债≈1860w、持仓 159.2万股,担保比 169% ⇒ 总资产≈3143w ⇒ 现价≈19.7;触 130% 需总资产≈2418w ⇒ 强平价≈15.2(约 −23%)。
3. **回撤情景表** —— 持仓 −5%/−10%/−20% 分别把担保比打到多少,是否破警戒线。
4. **仓位计算器** —— 做 3–5 分仓时,输入拟进板块/金额,反算加仓后担保比变化与安全缓冲。
5. **利息拖累** —— 年化 × 负债的月度成本(如 3.5%×1800w≈63w/年≈5.25w/月),显示每月打平线。

## 9. 分期

- **Phase 1 (MVP)**:数据层(AKShare 行情+资金流+Excel)→ 计算层(强度/扩散率/资金流/状态机 + **风控引擎**)→ 展示层(大盘云图 + 板块轮动排名 + 风险驾驶舱)。
- **Phase 2**:接 Tushare 干净历史 → 龙头联动分析页 + 历史联动验证页。
- **Phase 3**:人气龙头自动识别、盘中快照、(验证后才考虑)掘金/QMT 实时、可选 LLM 盘面综述。

## 10. 成功标准(MVP)

1. 跑一条命令完成收盘后全量更新,无需手动搬数据。
2. 大盘云图一眼看出当日主线板块与放量板块。
3. 轮动排名给每个板块正确打出状态标签。
4. 风险驾驶舱能在输入账户参数后,正确算出当前担保比与强平价,并对一笔拟加仓给出担保比影响。
