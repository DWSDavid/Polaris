## Task 9(修复):今日主线选择逻辑 —— 别被单日涨幅主导
**问题:** `Home` 用 `strength_rank` 选今日主线;strength 里 `relative_return`(今日涨跌)权重过高 → 高波动小盘(稀土)天天当主线。
**目标:** 新增**中期主线分 `mainline_score`**,以10日资金/趋势持续/扩散为主、今日涨跌为辅,并设流动性闸门(成交额低于全市场中位的板块不进主线候选)。今日主线 = `mainline_score` 最大者,并展示"为什么是它"(分项)。

**Files:** Create `src/compute/mainline.py`;Modify `src/app/Home.py`;Test `tests/test_mainline.py`
- [ ] **Step1 失败测试**
```python

        "pct_chg":[9.0, 1.2],          # 稀土今日猛涨
```

- [ ] **Step4 跑过** → PASS

**目标:** 用**近20日行业收益相关性**识别"老登(银行/保险/证券/公用/周期)↔ 新兴(电子/计算机/通信/电力设备)"负相关,给组合算对冲度。

**Files:** Create `src/compute/divergence.py`;Modify `src/compute/portfolio_exposure.py`;Test `tests/test_divergence.py`
- [ ] **Step1 失败测试**
```python

    rets = pd.DataFrame({"证券":[1,-1,1,-1,1.0], "电子":[-1,1,-1,1,-1.0]})
    corr = correlation_matrix(rets)
    assert corr.loc["证券","电子"] < -0.5
    assert hedge_score(["证券","电子"], corr) > 0.5
    assert ["证券","电子"] in hedge_pairs(["证券","电子"], corr, threshold=-0.3) \
```

- [ ] **Step4** 改 `portfolio_offset_report`:优先用相关性判对冲(负相关对→high/medium),资金流方向作为次要佐证。
