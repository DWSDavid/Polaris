## Task 34(根因②):AI 输出人话化(禁变量名 + 结构化 + 决策优先)
**问题:** facts 以原始 snake_case 喂 AI,AI 念 `positioninbox=1.0/ignitionflag=True`,一坨读不懂。
**目标:** AI 只说人话、先结论后展开、限长、禁止任何英文字段名/等号。

**Files:** Create `src/ai/humanize.py`;Modify `src/ai/summarize.py`/`advise.py`/`regime_brief.py`;Test `tests/test_humanize.py`
- [ ] **Step1 失败测试**
```python
# tests/test_humanize.py
from src.ai.humanize import humanize_facts, assert_no_jargon

def test_humanize_maps_to_chinese():
    h = humanize_facts({"position_in_box":1.0,"ignition_flag":True,"inflow_10d":30e8})
    text = str(h)
    assert "箱体位置" in text and "顶部" in text      # 1.0 → 顶部(高位)
    assert "启动迹象" in text
    assert "position_in_box" not in text and "ignition_flag" not in text
```
- [ ] **Step2 跑挂** → FAIL
- [ ] **Step3 实现** `humanize_facts(facts)`:把每个字段→中文标签+带单位的人话值(`position_in_box=1.0`→"箱体位置: 顶部(已高位,追高风险)";`inflow_10d`(元)→"10日主力: +30.0亿";`ignition_flag=True`→"启动迹象: 已出现";`dragontigerrows=96`→"龙虎榜: 活跃(96条)")。`assert_no_jargon(text)` 检测残留英文变量名。**喂 AI 前一律先 humanize**。
- [ ] **Step4** 改 prompt(summarize/advise/regime):
  - system 加:"**禁止出现任何英文字段名、变量名或等号**;只用中文短句;数字带单位。"
  - 结构:**先一句结论(适合/回避+核心理由)→ 再分点 → 每点≤2句**;总长≤200字。
  - `position_in_box` 高(≥0.9)时**必须提示"已在高位,追高需谨慎"**,不能盲推。
- [ ] **Step5** 输出后跑 `assert_no_jargon`,命中则重试一次/降级为本地人话摘要。
- [ ] **Step6 跑过** + 真网冒烟(贴一段新输出);commit `fix(v2.5): AI 人话化(禁变量名/先结论/限长/高位提醒)`
