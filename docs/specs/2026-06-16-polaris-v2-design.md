## 0. 北极星(收紧)
> 每天打开,一眼告诉我:**钱正在往哪个行业集中、这条主线已经跑了多久、还能不能跟、我该集中的龙头是哪几只,以及——我的选择是不是在自我对冲。**

## 1. 为什么重做 v1
v1 默认跑"股票池静态结构"(市值/权重的函数,`trend20`/`consecutive_up` 写死),板块状态与真实行情无关 → "没用"。v2 三条根本改动:
1. **分类换东财行业板块**(~86 个,银行/电力/非银金融/电子/通信…),对齐用户看的"大盘云图",且东财每行业**一次调用拿到实时主力净流入/涨跌/成交**。
2. **真实数据 + 每 10 分钟刷新**;趋势/相关性靠收盘历史。
3. **只看龙头/领先,硬过滤噪声**;加 **AI 解释+决策辅助**(grounded,人拍板)。

## 2. 用户约束 = 产品硬规则
- 持仓 **3–4 只**;**不做行业对冲**(看准节奏集中、拿住);**中期波段(1–3周)**,到点就撤、不贪。
- 1800w 融资杠杆、"不能亏" → **风控是脊柱**;AI **不自动下单**、不凭空编价格。
- → 系统默认主张永远是"**集中、同向、波段**";任何跨负相关板块的组合**标红警告**。

## 3. 信息架构 —— 混合C(治"难看难track")

### 3.1 首页(一屏三层)
1. **决策条(AI 综述)**:一段人话 ——
   > 「今日主线:**电力设备**(上升已持续 **9 个交易日**,主力 **10 日累计净流入 +X 亿**,扩散 72%)。⚠️ 你持仓 **银行 + 电子** 历史负相关,正在互相对冲。**非银金融** 接近拐点(资金 3 日转弱)。」
2. **大盘云图**(修复回来,东财行业 treemap):**大小=成交额/资金关注度,颜色=涨跌幅或主力净流入**。点行业下钻。
3. **主线候选表**:按"中期强度 + 资金持续"排序的前几个行业,带状态、已持续天数、龙头。

### 3.2 行业下钻页
- **中期趋势(1–3周)**:行业指数近 N 周走势 + **资金流 track(近几周每日净流入)** + 「**这条趋势已持续 X 天**」+ 拐点提示(资金/动能转弱)。
- **龙头列表**:每只 → **连涨/连跌已 X 天**、量价、换手、资金关注度、相对板块强弱、`龙头/中军/跟随` 角色;**点击展开**看近期走势与更多信息。
- **名词处处可解释**:冷启动、主力分化… 旁 `?` 点开 AI 用人话讲(含"为什么现在是这个状态")。

### 3.3 风险驾驶舱(沿用 v1 + 打通)
选一个想进的板块 → 加仓后担保比情景、距强平多远(v1 已有,v2.1 接回决策)。

## 4. 数据层(东财)
| 用途 | AKShare 函数(执行时核对) | 备注 |
|---|---|---|
| 行业板块实时(涨跌/成交/主力净流入) | `stock_board_industry_name_em` | 首页云图主数据 |
| 行业成分股 | `stock_board_industry_cons_em(symbol=...)` | 建股票池 |
| 行业历史(算趋势持续) | `stock_board_industry_hist_em(...)` | |
| **行业资金流多周期** | `stock_sector_fund_flow_rank(indicator="今日"/"5日"/"10日", sector_type="行业资金流")` | **直接给 1–3 周资金趋势** |
| 全市场个股快照(换手/成交额/市值/涨跌) | `stock_zh_a_spot_em` | 选龙头 + 噪声过滤 |
| 个股历史/资金流 | `stock_zh_a_hist`、`stock_individual_fund_flow` | 龙头连涨/量价 |

- **刷新**:每 10 分钟拉一次实时快照(云图、资金流、龙头量价);**收盘后落当日历史**(相关性、趋势持续天数靠历史)。缓存 parquet,实时快照 TTL 10 分钟。

## 5. 股票池(双龙头 + 热度 + 噪声过滤)
- **噪声硬过滤**:剔 ST/*ST、上市<1年(次新)、总市值 < 阈值、近 5 日均成交额 < 阈值。
- **每东财行业选龙头**:综合分 = 市值 + 流动性 + **资金关注度(成交额)** + **换手率** → 取 Top5–8 作"市值龙头/中军"种子。
- **人气龙头**:用户手工加入(东财、拓维这类市值不大却是真龙头),`leader_type=momentum`。
- 股票池是**动态观察网络**,每日更新种子 + 保留手工名单。

## 6. 计算层(三个让它"有用"的引擎)
1. **趋势持续 & 拐点**(板块+龙头两层):当前趋势连续天数(连涨/连跌、资金连续净流入天数);拐点 flag = 资金由流入转流出 / 量价背离 / 动能减弱。回答"持续多久了 / 是不是该撤"。
2. **分化/对冲引擎(v2.1,用户最痛点)**:行业两两相关性矩阵,识别"老登(银行/公用/周期)↔ 新兴(科技/成长)"负相关;对用户勾选的候选/导入持仓算**对冲度**,跨负相关板块 → **标红警告"你在自我对冲"**。
3. **风控引擎**(v1 已有):担保比/强平/加仓情景,v2.1 接回决策条。
- (联动历史胜率、"还能走多久"历史类比 → v2.2。)

## 7. AI 层(解释 + 决策辅助,grounded)
- **输入只喂系统算出的真实数值**(板块状态/资金多周期/趋势持续天数/分化矩阵/龙头量价)。**禁止编造价格、资金、个股名**。
- **输出**:① 名词解释(冷启动/主力分化…) ② 板块综述(人话,含"类似历史情形后通常还能走多久"的定性) ③ 决策辅助(当前主线建议集中哪个板块、持仓是否对冲、哪个接近拐点该撤)。
- **模型**:默认 **DeepSeek**(`DEEPSEEK_API_KEY`/`DEEPSEEK_MODEL`),GPT(`OPENAI_API_KEY`)兜底,可切 Qwen。**人最后决定,AI 不下单。**

## 8. 分期(先有用,UI 美化放最后)
- **v2.0 — 接东财 + 让它有用**:东财数据客户端、噪声过滤+股票池重建、趋势持续&拐点 stat、板块中期趋势&资金track、名词解释、**AI 板块综述**、**大盘云图修复重做** + 首页决策条、行业下钻页。(UI 求"能读",不求美。)
- **v2.1 — 决策辅助**:分化/对冲引擎、决策条增强(主线建议/对冲警告/该撤)、风控打通。
- **v2.2 — 进阶**:龙头联动历史胜率、拐点打磨、"还能走多久"历史类比统计。
- **v2.3 — UI 设计美化(最后)**:治"太抽",统一设计语言/色板/排版,删除无意义代码块,名词 tooltip 视觉,龙头展开交互。

## 9. 成功标准
1. 首页**真实**反映当日(决策条数值与云图对得上;非接通时明确标红"静态")。
2. 一眼看出今日主线 + 钱往哪。
3. 任一行业能答"趋势持续多久 + 是否接近拐点";龙头能展开看连涨天数与走势。
4. v2.1:勾选 3–4 只候选若跨负相关板块,**自动警告对冲**;选板块能看加仓后担保比。
5. 名词都能点开解释。
