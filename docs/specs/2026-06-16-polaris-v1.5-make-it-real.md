# Polaris v1.5 — 「把它变真」改进计划

> **执行说明(给 Codex):** 按 P0 → P1 → P2 顺序。纯逻辑任务走 TDD(先写失败测试→跑挂→实现→跑过→commit);UI 任务按"验收点"手动跑通。**每个 Task 一个 commit。** 不要碰其它 Task 的文件。

**背景:** v1 已完成 16 个 Task、40 测试通过,但**默认仪表盘跑的是股票池静态结构(seed_static),不是真实行情** —— 板块强度/状态/资金流全是市值与权重的函数,`trend20`/`consecutive_up` 写死。导致"看起来在做轮动,其实没用"。本计划把它接上真实 EOD 行情,让解释带数字,并重做 UI。

**核心原则:**
1. **要么真,要么明说没有。** 没接到行情时,不准展示伪造的状态标签 —— 显式标红"静态结构,非实时信号"。
2. **解释必须引用真实数值**(哪个板块、扩散率%、资金几亿、龙头是谁、比谁强)。
3. **UI 语义化** —— 颜色=状态,大小=成交额(钱),一眼看出今日主线。

```python
# src/compute/trend.py
"""个股趋势 / 连涨,用真实日线序列(按日期升序)。"""
import pandas as pd

def trend_sign(closes: pd.Series, window: int = 20) -> int:
    closes = closes.dropna()
    if len(closes) < window + 1:
        return 0
    ref, now = closes.iloc[-(window+1)], closes.iloc[-1]
    if now > ref: return 1
    if now < ref: return -1
    return 0

def consecutive_up_days(pct: pd.Series) -> int:
    n = 0
    for v in reversed(pct.dropna().tolist()):
        if v > 0: n += 1
        else: break
    return n
```

- [ ] **Step 4:** 改 `enrich_stock_panel_with_market_data` —— 除最新行外,额外保留每股 `trend20`(用全序列 close 算 `trend_sign`)与 `consecutive_up`(用全序列 pct 算)。`build_market_sector_panel` 的 `trend20` 改为板块内 `trend20` 众数/符号均值,`consecutive_up` 改为板块内中位数。删掉用 `avg_pct_chg` 的近似。
