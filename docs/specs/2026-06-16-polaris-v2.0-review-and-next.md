# 阶段 A —— 清理(进 v2.1 之前必须做完)

## A1. 修 3 个 AI 测试(测试隔离)
**现象:** `tests/test_ai.py::test_chat_returns_placeholder_without_key`、`tests/test_ai_brief.py::test_has_openai_key_reads_environment`、`::test_has_ai_key_reads_selected_provider_environment` 失败。
**根因:** 用户已把真 key 填进 `.env`;`ai_client.chat` / `ai_brief.has_*` 在调用时 `load_dotenv()`,把被 `monkeypatch.delenv` 删掉的 key 又从 `.env` 读回来。
**修法(二选一):**
- 测试里同时 `monkeypatch.setattr("src.ai.ai_client.load_dotenv", lambda *a, **k: None)`(及 ai_brief 对应),再 delenv;或
- 生产代码改为模块加载时 `load_dotenv()` 一次,函数内不再调用;测试用 monkeypatch.delenv 即可。
- [ ] 改完 `pytest -q` 必须 110 全绿。commit:`fix(v2.0): 隔离 AI key 测试不受 .env 真实 key 影响`

# Idea Backlog(候选新功能,按用户哲学排序;用户挑选后并入)

> 用户哲学锚点:中期波段(1–3周)、持仓 3–4 只、**不做行业对冲**、只玩龙头、到点就撤不贪、护担保比。

1. **【强烈推荐·v2.1】候选篮子 = 每日决策驾驶舱**
   持久保存你的 3–4 只持仓/候选 → 实时显示:① 组合对冲度(跨负相关板块标红)② 每只的趋势持续天数/拐点 ③ 主线对齐度 ④ 加这些后的担保比安全垫。把"分化对冲引擎"做成你每天先看的那一屏。

2. **【强烈推荐·v2.2】"还能走多久"历史类比**
   对处于 state X、已持续 Y 天的板块,检索历史相似 setup → 之后**中位还能走几天 / 收益分布 / 最大回撤**。直接回答你反复问的"还会持续多久",服务"到点就撤"。

3. **【推荐·v2.1】离场纪律提醒**
   持仓板块出现 拐点(资金转弱/量价背离/连涨天数超历史分位)→ 明确"考虑减仓"提示。把"不贪最后一杯羹"变成系统纪律。

4. **【推荐·v2.2】资金接力图(rotation flow)**
   近 N 日板块净流入的此消彼长,看清钱从"金融→科技→…"怎么接力,辅助"看准节奏就进"。

5. **【中·v2.2】估值护栏**
   每板块市盈率历史分位(`fundamentals.py` 已有)→ 追高时若估值已在高分位,标黄"别在高位追"。

6. **【中·v2.2】龙头→中军联动确认**
   龙头放量大涨后中军 T+1/3/5 跟涨概率,确认"真板块行情"还是"单票脉冲"(原 `linkage_stats` 升级)。

7. **【轻】龙头白名单锁定**
   一键把观察域锁到你信任的龙头清单,噪声永不出现。

8. **【轻】EOD 快照存档 + 两周回放**
   10 分钟快照落库,支持"这条主线这两周怎么走的"回放(`rotation_history.py` 已有基础)。
