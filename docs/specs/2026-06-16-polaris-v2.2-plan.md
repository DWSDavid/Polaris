# Polaris v2.2 实施计划 —— 中期周期视角(拉长窗口 / 启动迹象 / 回撤容忍 / 市场context)

> **执行说明(给 Codex):** 在 v2.1 之后执行。按 Task 15→20 顺序,纯逻辑 TDD,每 Task 单独 commit。⚠️ 标注处先用真实 AKShare 调用核对函数名/列名。**context 数据一律走 AKShare 现成东财接口,禁止写网页爬虫。** UI 美化仍留 v2.3。

**核心转向:这是中期波段工具(持有几周~1-2个月),不是日内。** 所以:
- 指标窗口从"今日/20日"拉长到 **60/120日 + 箱体区间**,判断的是**周期**不是当天。
- **小回撤(-8~-10%)默认容忍**,只有中期结构破坏才提示离场。
- 新增**启动迹象**探测(低位/箱体 → 启动),服务"看准节奏就进"。
- 用 AKShare 东财 context(北向/龙虎榜/研报/新闻)喂 AI 辅助判断。

参考:[v2 设计](2026-06-16-polaris-v2-design.md)、[v2.1 计划](2026-06-16-polaris-v2.1-plan.md)。

## Task 17:回撤容忍的离场升级(改 v2.1 的 exit_signal)
**目标:** 中期视角下,小回撤不报警;只有**中期结构破坏**才提示离场。

**Files:** Modify `src/compute/exit_signal.py`;Test `tests/test_exit_signal.py`(补)
- [ ] **Step1 失败测试**
```python
def test_small_pullback_in_uptrend_is_noise():
    row = {"pullback_from_high":0.08, "midterm_trend":1, "price_above_ma60":True,
           "cum_inflow_20d":5e8, "below_box_low":False}
    assert exit_flag(row)["exit"] is False        # -8%回撤但中期结构完好 → 不撤

def test_structural_break_triggers_exit():
    row = {"pullback_from_high":0.15, "midterm_trend":-1, "price_above_ma60":False,
           "cum_inflow_20d":-6e8, "below_box_low":True}
    assert exit_flag(row)["exit"] is True
```
- [ ] **Step2 跑挂** → FAIL
- [ ] **Step3 实现** `exit_flag`:离场条件改为(满足任一结构破坏)——`below_box_low` 或 `price_above_ma60 is False` 或 `cum_inflow_20d<0 且持续` 或 中期趋势转 -1。**单纯 `pullback_from_high`≤容忍带(默认0.10)且中期趋势=1 且资金仍净入 → 不离场**(返回 `{"exit":False,"reason":"中期结构完好,回撤属正常"}`)。保留 v2.1 的拐点/超期作为"减仓观察"弱提示,与"离场"强信号分级。
- [ ] **Step4 跑过** → PASS
- [ ] **Step5 commit** `fix(v2.2): 离场信号改为容忍小回撤,只在中期结构破坏时触发`
